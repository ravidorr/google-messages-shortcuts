Actions

The extension automates conversation-list actions on Google Messages Web: archive, trash, mark read or unread, mute, unmute, block / report spam, open Archived, open Spam & blocked, start chat, and unarchive (via Google Messages native controls in the Archived dialog).

  • Archive, trash, mark read, and mark unread use Chrome extension keyboard shortcuts (defaults below).
  • Mute, unmute, and block / report spam appear as row pills (Chrome allows four shortcuts per extension).
  • Optional Chrome commands: Open Archived, Start chat, and Open Spam & blocked.
  • Row pills do not appear inside the Archived dialog; use Google Messages unarchive controls there.

Chrome shortcuts

Chrome controls extension shortcuts. Open Chrome shortcut settings or visit chrome://extensions/shortcuts and assign keys for Messages Shortcut Actions.

Default row-action shortcuts

Action Windows / Linux macOS
Archive conversation Ctrl+Shift+Y Command+Shift+Y
Trash conversation Ctrl+Shift+D Command+Shift+D
Mark as read Ctrl+Shift+K Command+Shift+K
Mark as unread Ctrl+Shift+U Command+Shift+U

Assign optional navigation commands (Open Archived, Start chat, Open Spam & blocked) in the same Chrome shortcuts page. If a key combination is already used by Chrome or your OS, choose another.

Page navigation

Page-local shortcuts run only on Google Messages Web. They ignore editable fields, IME composition, native dialogs, open row menus, repeated key presses, and selected text. When the extension is paused, navigation shortcuts and the command palette are blocked.

Press Shift+/ on Google Messages for the in-page shortcut reference.

Action Windows / Linux macOS
Next conversation Alt+ArrowDown Option+ArrowDown
Previous conversation Alt+ArrowUp Option+ArrowUp
Open focused conversation Alt+Enter Option+Enter
Return to previous conversation Alt+[ Option+[
Next unread Alt+U Option+U
Previous unread Alt+Shift+U Option+Shift+U
Return focus to conversation list Escape Escape
Command palette Ctrl+Shift+P Command+Shift+P
Focus composer Alt+M Option+M

List and unread navigation cover loaded rows only. The command palette filters command labels and descriptions; it does not search conversations or message content.

Preferences

Change these in the extension popup on Google Messages Web.

Trash confirmation

Automatically confirm Move to trash (default on) confirms Google Messages native trash dialog when you use a trash shortcut or pill.

Conversation opening

Open conversations on hover or focus (default off) opens a conversation when you hover or tab to its row. Mark as read remains an explicit action and follows Google Messages behavior for selecting a conversation.

Pill visibility

  • On hover or focus (default): pills on hover, keyboard focus, or selected row.
  • On selected row only: pills only when Google Messages marks the row focused.
  • Hidden: no pills; keyboard shortcuts still work.

Pause and reset

Pause shortcut actions and pills disables extension shortcuts and pills on Google Messages without changing native Google Messages behavior.

Reset extension preferences restores popup defaults only. It does not change conversations in Google Messages or store message content.

Limitations

  • Google Messages UI can change; menu targeting may break after updates.
  • Mark as read uses row open when no row-menu control exists in the current UI.
  • Pin and unpin are not available in Google Messages Web row menus.
  • Block / report spam opens Google Messages native dialog; you confirm block and spam choices there.
  • Open Spam & blocked is validated for the English UI chrome; ambiguous or missing controls fail closed.
  • Shortcut automation depends on Google Messages accepting programmatic clicks.

Privacy

The extension does not collect or transmit conversation content. Preferences are stored locally in Chrome. Return-to-previous conversation navigation keeps the last opened link in memory only for the session.

Install

Install from the Chrome Web Store or load an unpacked build from the GitHub repository (dist/ after npm run build).

Requires Google Chrome or another Chromium browser with Manifest V3 and an open Google Messages Web tab.
