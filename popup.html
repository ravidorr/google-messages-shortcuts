Messages Shortcut Actions

Archive, trash, read/unread, mute, block / report spam, and open Archived from Google Messages conversation rows.

Keyboard shortcuts

    One or more shortcuts are not assigned. Open Chrome shortcut settings to configure them.

    Navigation shortcuts

      Navigation shortcuts run on the Google Messages page. Mute, unmute, and block / report spam are row pills only (no manifest shortcut slot). The Archived dialog uses Google Messages' native Unarchive controls. Block / report spam opens Google Messages' native dialog and focuses the final confirmation control without auto-clicking.

      Change shortcuts

      Chrome controls extension shortcuts. Open chrome://extensions/shortcuts and assign keys for this extension.
